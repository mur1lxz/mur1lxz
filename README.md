## 📌 Projetos

### 🤖 Automação com n8n + WhatsApp

Projeto de automação utilizando **n8n, APIs e inteligência artificial**, com integração ao WhatsApp para automatizar processos e interações.

**Tecnologias:** `n8n` `APIs` `WhatsApp` `IA`

---

### 🏢 Sistema de monitoramento de consumo

Projeto de automação desenvolvido para facilitar o acompanhamento do consumo de **energia, água e gás** de um prédio através de um sistema SaaS.

A solução utiliza automações e integrações com APIs para organizar e apresentar os dados de consumo.

**Tecnologias:** `n8n` `APIs` `SaaS` `Automação`

---

### 🛠️ APAS — Análise Preliminar de Avarias em Sistemas

Sistema desenvolvido em Python baseado nas metodologias **FMEA e RCFA**, com funcionalidades para análise de falhas e cálculo de RPN.

O projeto utiliza armazenamento em JSON, geração de relatórios e organização dos dados através de classes.

**Tecnologias:** `Python` `JSON` `Pandas` `POO`
